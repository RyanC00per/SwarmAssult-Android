# 🐜 Swarm Assault – Android Port

### The classic insect-themed real-time strategy game, now running on Android!

**Swarm Assault Android** is an unofficial community project bringing the classic 1999 RTS game *Swarm Assault* to Android devices.

Built using **OpenSA** and the **OpenRA engine**, this port aims to make the classic strategy experience accessible to Android players.

## 🎮 Project Status

**Version:** 1.1.3  
**Status:** Working Android build — public release pending  
**Platform:** Android  
**Engine:** OpenRA / OpenSA

A working Android APK has been successfully built and tested, including a fix for colony production and factory selection.

The project is still being prepared for public distribution.

## ✨ Features

- Classic Swarm Assault gameplay on Android
- OpenSA-based game engine
- Original RTS mechanics and missions from the OpenSA recreation
- Android APK build
- Factory and production selection fix in version 1.1.3

Device compatibility, controls and performance may vary.

## 📥 Download

**The APK is not publicly available yet.**

The current build contains original Swarm Assault game assets. Their redistribution rights need to be clarified before a public release.

The goal is to make the Android version freely available to the community if a suitable distribution solution can be established.
